مشروع ١: تتحكم في جهازك٦ دروس

أداة pc.ps1 بتقفل الجهاز أو تعمله restart بعد مهلة، وتلغي المعاد، وتقولك فيه معاد ولا لأ. هنبنيها على ٦ خطوات.

مشروع ١ — الواجهة الأولاكتب شكل الاستخدام قبل أي كود

أول خطوة في أي أداة مش الكود، دي شكل الاستخدام. تكتب الأوامر اللي نفسك تكتبها، وبعدين تبني اللي يخليها تشتغل.

الأداة اللي هنبنيها اسمها pc.ps1: .\pc.ps1 off -In 30 اقفل بعد ٣٠ دقيقة. .\pc.ps1 cancel الغي المعاد. .\pc.ps1 status فيه معاد متجدول؟

والخطوة الأولى في الكود هي هيكل فاضي بيطبع اللي استقبله بس، عشان تتأكد إن PowerShell فهم الـ arguments زي ما انت قاصد.

الشرح خطوة بخطوة

الفكرة

قبل أي كود: إيه الشكل اللي نفسي أكتبه في الترمنال؟

١. الواجهة اللي اتفقنا عليها

شكل الاستخدام
.\pc.ps1 off -In 30
.\pc.ps1 cancel
.\pc.ps1 status

٢. الهيكل الفاضي

powershell
param(
    [string]$Action = 'status',
    [int]$In = 0
)

Write-Host "Action = $Action"

param( بتفتح قايمة المدخلات. لازم تبقى أول كود في الملف.

٣. نشغّله

الناتج
Action = status
In     = 0

الخلاصة

  • ابدأ بشكل الاستخدام مش بالكود.
  • param() أول كود في الملف.

ليه

أغلب السكربتات الوحشة اتكتبت من الآخر للأول: الكود الأول، والاستعمال طلع لوحده.

إزاي

الهيكل الفاضي بيأكد ٣ حاجات: الملف بيشتغل، و PowerShell فهم الـ arguments صح، والقيم الافتراضية شغالة.

امتى

أول خطوة في أي سكربت هتكتبه. حتى لو ١٠ سطور.

غلطات شائعة

تحط أي كود قبل param(). وتنسى .\ قدام اسم السكربت.

مثال
param(
    [string]$Action = 'status',
    [int]$In = 0
)

Write-Host "Action = $Action"
Write-Host "In     = $In"

شرح السطور

  1. param(بداية قايمة المدخلات، ولازم تبقى أول كود في الملف
  2. [string]$Action = 'status',الفعل: نص، والافتراضي status
  3. [int]$In = 0المهلة بالدقايق: رقم صحيح، والافتراضي صفر
  4. )قفل الـ param
  5. Write-Host "Action = $Action"اطبع اللي وصلنا عشان نتأكد
  6. Write-Host "In = $In"ونفس الحاجة للرقم
جرّب

احفظه باسم pc.ps1، وشغّله تلات مرات: لوحده، وبـ -Action off -In 30، وبـ off -In 30.

مشروع ١ — التحقق من المدخلاتخلي الأداة ترفض الغلط قبل ما تشتغل

دلوقتي الأداة بتقبل أي حاجة: .\pc.ps1 sleep هتعدّي، و -In 99999 كمان. الخطوة دي بتخلي PowerShell يرفض الغلط لوحده.

[ValidateSet(...)] فوق الـ parameter: القيم المسموحة دي بس. [ValidateRange(0, 10080)] للأرقام.

الشرح خطوة بخطوة

الفكرة

بدل ما تكتب if لكل مدخل، بتعلّق شروط فوق الـ parameter.

١. المشكلة

الناتج
Action = sleep
In     = 99999

ليه

لو سبت الفحص لجسم السكربت، Tab مش هيعرف يساعد.

إزاي

كل الـ attributes فوق الـ parameter.

امتى

على كل parameter.

غلطات شائعة

تحط الـ attribute تحت الـ parameter بدل فوقه.

مثال
param(
    [Parameter(Position = 0)]
    [ValidateSet('off', 'restart', 'cancel', 'status')]
    [string]$Action = 'status',

    [ValidateRange(0, 10080)]
    [int]$In = 0
)
جرّب

جرّب .\pc.ps1 sleep و .\pc.ps1 off -In 99999 وشوف الرسالتين.
