# الترمنال بإيدك

صفحة مذاكرة للترمنال: bash و PowerShell و CMD و zsh، وإدارة السيرفر، و Git و Docker و PostgreSQL و Nginx وغيرهم.
كل درس فيه شرح، ومثال تنسخه، وتجربة تعملها بإيدك، وشرح عميق، وشرح المثال سطر سطر.

## الفتح

- **من النت:** لينك GitHub Pages بتاع الـ repo.
- **على الكمبيوتر:** افتح `index.html` بدبل كليك.
- **ملف واحد (من غير نت، أو تبعته لحد):** `dist/terminal.html`.

## الملفات

| الملف | فيه إيه |
|---|---|
| `js/tabs/*.js` | ملف لكل تاب. **هنا بيتعمل ٩٠٪ من التعديلات** |
| `js/extras.js` | جدول «نفس المهمة في التلاتة» والتحديات |
| `index.html` | هيكل الصفحة: كروت التابات وترتيب المذاكرة |
| `css/style.css` | الشكل والألوان |
| `js/core.js` | الأساس اللي بيسجّل كل تاب |
| `js/app.js` | العرض والبحث والتقدم و«اختبرني» |
| `tools/check.js` | فحص المحتوى |
| `tools/build.js` | تجميع الملف الواحد |

## شكل الدرس

```js
{
  cmd: "grep",                    // الاسم، فريد جوه التاب (التقدم محفوظ بيه، فمتغيّروش من غير سبب)
  title: "دوّر جوه الملفات",       // بيظهر كسؤال في «اختبرني»
  desc: R`الشرح. [[كلام]] بيتعرض كـ code.`,
  example: R`grep -n "error" app.log
grep -r "TODO" src/`,
  try: R`التجربة`,
  flag: "danger",                 // اختياري
  deep: { why: R`...`, how: R`...`, when: R`...`, mistakes: R`...` },
  lines: [R`شرح السطر الأول`, R`شرح التاني`]   // واحد لكل سطر أمر في المثال
}
```

التفاصيل الكاملة مكتوبة في أول كل ملف تاب.

## بعد أي تعديل

```bash
npm run check    # بيدوّر على الأخطاء: شرح سطور ناقص، اسم متكرر، رابط قاموس بايظ...
npm run build    # بيفحص، وبعدين يعمل dist/terminal.html من جديد
```

مش محتاج `npm install`، مفيش مكتبات. محتاج Node بس.
ولما تعمل push، GitHub بيشغّل نفس الفحص، وبيقولك لو نسيت تعمل build.

## تاب جديد

1. انسخ أي ملف في `js/tabs/` وغيّر اسم التاب في `TAB("...")`.
2. ضيف `<script src="js/tabs/اسمه.js"></script>` في `index.html` قبل `extras.js`.
3. ضيف كارت ليه في `index.html` (`<button class="sw" ... data-s="اسمه">`)، وألوانه في `css/style.css` (دوّر على `data-shell` و `data-s` و `data-k`).
