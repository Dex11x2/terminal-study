# الترمنال والبرمجة بإيدك (أكاديمية مهندس البرمجيات)

أضخم منصة مذاكرة تفاعلية بالمصري لمهندس البرمجيات: من الترمنال (bash و PowerShell و CMD و zsh)، وإدارة السيرفرات والـ DevOps (Docker و Nginx و VPS و CI/CD)، إلى لغات البرمجة (JavaScript, TypeScript, Python, Go, C++, C#, Java, Dart, Kotlin, Swift)، وتطوير الـ Full Stack (React, Next.js, Angular, Node, FastAPI, PHP)، وقواعد البيانات (SQL, PostgreSQL, MongoDB)، وهندسة البرمجيات والمعمارية، وهياكل البيانات والخوارزميات (DSA)، و 7 مشاريع كاملة للإنتاج، وتحضير المقابلات وسوق العمل، وتاب «الرموز» اللي بيشرح كل رمز بتقابله في الترمنال والكود.
كل درس فيه شرح، ومثال تنسخه، وتجربة تعملها بإيدك، وشرح عميق، وشرح المثال سطر سطر، مع أكثر من 150 تمرين يصحح نفسه تلقائياً بمحرك Postgres و JS حقيقي بدون نت.

## الفتح

- **من النت:** لينك GitHub Pages بتاع الـ repo.
- **على الفون كتطبيق:** افتح اللينك، ومن قايمة المتصفح اختار «Add to Home screen» (أو «Install app»). بعد أول فتحة بيشتغل من غير نت.
- **على الكمبيوتر:** افتح `index.html` بدبل كليك.
- **ملف واحد (من غير نت، أو تبعته لحد):** `dist/terminal.html`.

## شكل الدرس

```js
{
  cmd: "grep",                    // الاسم، فريد جوه التاب (التقدم محفوظ بيه، فمتغيّروش من غير سبب)
  title: "دوّر جوه الملفات",       // بيظهر كسؤال في «اختبرني»
  desc: R`الشرح. [[كلام]] بيتعرض كـ code.`,
  example: R`grep -n "error" app.log
grep -r "TODO" src/`,
  try: R`التجربة`,
  flag: "danger",                 // اختياري
  deep: { why: R`...`, how: R`...`, when: R`...`, mistakes: R`...` },
  lines: [R`شرح السطر الأول`, R`شرح التاني`],  // واحد لكل سطر أمر في المثال
  sol: R`الحل والناتج المتوقع للتجربة`,   // اختياري، بيظهر مقفول تحت «جرّب»
  solCode: R`كود الحل`,                  // اختياري
  check: { lang: "js", starter: R`...`, tests: R`...`, solution: R`...` }  // اختياري: تمرين بيتصحح لوحده (تحت)
}
```

التفاصيل الكاملة مكتوبة في أول كل ملف تاب.

## تمرين بيتصحح لوحده (`check`)

أي درس ممكن يبقى فيه مربع كود وزرار «شغّل واختبر». لو كل الاختبارات عدّت، الدرس بيتعلّم عليه «جربتها» لوحده.

**JavaScript:**

```js
check: {
  lang: "js",
  starter: R`function sum(a, b) {}`,          // اختياري: الكود اللي الطالب بيبدأ بيه
  tests: R`test("1 + 2", () => expect(sum(1, 2)).toBe(3));`,
  solution: R`function sum(a, b) { return a + b; }`  // لازم: حل مرجعي مش بيظهر، الفحص بيتأكد إنه بيعدّي
}
```

- الاختبارات بتشوف دوال الطالب لأنها بتتشغل بعد كوده في نفس المكان. المتاح: `test(name, fn)` و `expect(x).toBe(y)` و `.toEqual(y)` (مقارنة عميقة) و `.toThrow("جزء من الرسالة" أو /regex/)` و `.toBeTruthy()` و `.toBeFalsy()`، و `console.log` بيظهر تحت النتيجة.
- الكود بيتشغل في Web Worker، ولو مخلصش في ٣ ثواني بيتقفل. بيشتغل من `index.html` كملف، ومن `dist/terminal.html`، ومن غير نت.
- الفحص بيدعم الاختبارات اللي بتخلص من غير ما تستنى timer (`setTimeout`) أو نت.
- جوه `R` نفس القاعدة: `${` تتكتب `$__{`، و backtick يتكتب `$__bt`.

**SQL (PostgreSQL حقيقي):**

```js
check: {
  lang: "sql",
  setup: R`CREATE TABLE users (id int, name text); INSERT INTO users VALUES (1, 'Sara');`,
  starter: R`SELECT ...`,                  // اختياري
  expect: [[1, "Sara"]],                   // الصفوف المتوقعة، أو بدلها:
  // expectSql: R`SELECT id, name FROM users`,   استعلام مرجعي والصفوف بتطلع منه
  solution: R`SELECT id, name FROM users;`,     // لازم مع expect، واختياري مع expectSql
  ordered: false                          // اختياري: true لو الترتيب جزء من الإجابة (ORDER BY)
}
```

- كل تشغيل بيبدأ من قاعدة نضيفة: `setup` وبعدين استعلام الطالب، وبتتقارن نتيجة آخر `SELECT`. أسماء الأعمدة مش مهمة، والأرقام بتتقارن كأرقام (`count()` و `2.50` زي `2` و `2.5`)، والترتيب مش مهم إلا لو `ordered: true`.
- المحرك PGlite (Postgres 17 مبني WASM، حوالي ٦ ميجا). مش بيتحمّل غير لما الطالب يوصل لأول مربع SQL، و الـ service worker بيحفظه في كاش لوحده، فبعد أول مرة بيشتغل من غير نت. الاستعلام اللي مبيخلصش في ٥ ثواني بيتقفل.
- **القرار:** تمارين SQL محتاجة الموقع (GitHub Pages) أو التطبيق المتسطب. `index.html` المفتوح كملف و `dist/terminal.html` بيعرضوا «التمارين دي محتاجة النسخة الأونلاين أو التطبيق»، لأن المتصفح مبيسمحش يحمّل worker و WASM من `file://`، وحشر ٦ ميجا جوه الملف الواحد (اللي هو أصلًا حوالي ١٨ ميجا) مش مستاهل. تمارين JavaScript شغالة في كل النسخ.
- `npm run check` بيشغّل PGlite في Node على كل تمرين: الـ `solution` لازم يطلّع الصفوف المتوقعة.

## المراجعة والامتحانات

- **«اختبرني»** بيختار البطاقات بالوزن: اللي ميعاد مراجعتها جه الأول، وبعدين الجديدة، واللي نسيتها كتير بتتكرر أكتر.
- **«عليك مراجعة (N)»** فوق: البطاقات اللي ميعادها جه من كل التابات. كل «عرفتها» بتنقل البطاقة صندوق لقدام (بترجع بعد ١ ثم ٣ ثم ٧ ثم ١٦ ثم ٣٥ يوم)، و «لسه» بترجّعها للصندوق الأول. التقدم القديم (`fc:`) بيتحوّل لوحده من غير ما يضيع.
- **«امتحان المستوى»** جنب المستويات وفي أول كل مستوى: ١٠ دروس عشوائية (أو كلهم لو أقل)، وتعدّي بـ ٨ من ١٠. المستوى اللي عدّيته بيظهر عليه ✓، وآخر نتيجة بتظهر جنب الزرار.
- المحفوظ في المتصفح: `done:` و `note:` و `fc:` زي الأول، و `srs:<tab>:<cmd>` = `{box, due}`، و `exam:<tab>:<level>` = `{last, pass}` (كل واحد `{score, n, date}`)، و `chk:<tab>:<cmd>` = `1` لما التمرين يعدّي، و `code:<tab>:<cmd>` = كود الطالب. كلهم بيتنزلوا في «نزّل نسخة من تقدمي».

## بعد أي تعديل

```bash
npm run check    # بيدوّر على الأخطاء: شرح سطور ناقص، اسم متكرر، رابط قاموس بايظ...
npm run build    # بيفحص، وبعدين يعمل dist/terminal.html من جديد
```

ولو جربت دروس بجد (الأوامر اتشغّلت على النظام نفسه)، سجّلها:

```bash
node tools/verify.js                                   # الملخص: اتراجع، اتعدّل بعد المراجعة، لسه
node tools/verify.js todo bash                         # اللي محتاج مراجعة في تاب bash ومكانه
node tools/verify.js mark bash "PS1" --on "ubuntu-24.04"  # الدرس ده اتجرّب بشكله الحالي
```

مش محتاج `npm install`: المكتبة الوحيدة (PGlite لتمارين SQL) محطوطة جاهزة في `vendor/`. محتاج Node 18 أو أحدث بس.
ولما تعمل push، GitHub بيشغّل نفس الفحص، وبيقولك لو نسيت تعمل build.

## تاب جديد

1. اعمل فولدر `js/tabs/اسمه/` وانسخ فيه `01.js` من أي تاب، وغيّر اسم التاب في `TAB("...")`.
2. ضيف `<script src="js/tabs/اسمه/01.js"></script>` في `index.html` قبل `extras.js`. ولما الملف يعدّي حوالي ١٢٠٠ سطر، انقل أقسام لملف جديد `02.js` بيبدأ بـ `MORE("اسمه", [` وضيفه في `index.html` بعد `01.js` على طول.
3. ضيف كارت ليه في `index.html` (`<button class="sw" ... data-s="اسمه">`)، وألوانه في `css/style.css` (دوّر على `data-shell` و `data-s` و `data-k`، والمتغير `--a-اسمه` في الوضع الفاتح والغامق).
4. لو التاب دروس وكود مش أوامر ترمنال (زي JavaScript و Go)، ضيف اسمه في `LESSON_TABS` في `js/app.js`. من غيره العدّاد هيقول «أمر» بدل «درس»، وكود الحل هيتعرض كأوامر ترمنال بـ `$` قدام كل سطر.
5. ضيف اسمه المعروض في `TAB_NAMES` في `tools/check.js` عشان روابط القاموس تشاور عليه.
6. ضيفه في «ترتيب المذاكرة» في `index.html` في المكان اللي المفروض يتذاكر فيه.
7. `npm run build`.

## قواعد كتابة الدروس

- **اللغة:** مصري زي باقي الصفحة («عشان» و «هتلاقي» و «لو»)، مش فصحى («يمكنك» و «سوف»). المصطلح التقني يفضل إنجليزي جوه `[[ ]]`.
- **التعليقات في المثال بصيغة اللغة نفسها:** `//` في JavaScript و TypeScript و Java و Kotlin و Swift و Go و C و C++ و Dart و PHP، و `#` في bash و Python و YAML بس. المثال بيتنسخ ويتشغّل، فتعليق `#` في كود Go أو C++ معناه إن الطالب هينسخ كود مش بيشتغل. `npm run check` بيمسك الغلطة دي في تابات اللغات دي.
- **أي رمز يظهر لأول مرة يتشرح:** `*` و `&` و `->` و `:=` و `?.` وغيرهم. ولو الرمز ليه درس في تاب «الرموز»، شاور عليه.
- **مفيش مبالغة:** من غير «الأسرع في العالم» و «الخارق». معلومة دقيقة أحسن من حماس.
- **المثال لازم يتشغّل:** والناتج اللي في `sol` يبقى الناتج الحقيقي.
- **`desc` هو مقدمة الدرس وبيظهر كله:** أول فقرة فيه هي الخلاصة (هي اللي بتفضل ظاهرة في «شرح مختصر»)، فخليها جملة أو اتنين بيقولوا الأمر بيعمل إيه. والسطر الجديد جوه الفقرة بيظهر سطر جديد، فالقوايم (• أو 1.) تتكتب كل بند في سطر.
